# Changelog

## Unreleased

## 0.9.0

### Added

- `--max-width` cuts cells that are longer than a given number of characters.

## 0.8.0

### Deprecated

- `--compact` (`-c`) is deprecated and will be removed in 1.0. It prints a warning on stderr. Use `--max-width` to keep output narrow.

## 0.7.0

### Added

- `--border` draws `|` between the columns.
