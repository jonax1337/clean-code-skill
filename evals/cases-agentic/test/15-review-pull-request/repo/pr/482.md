# PR 482: User search, paged user list, bulk deactivation with audit log

Author: dana
Patch: `pr/482.diff`

## What changes

- `list_users` takes `page` and `per_page` (pages start at 1, as documented in the README) and the handler now also
  returns `page` and `pages` so the console can render a pager.
- New `search` handler: `q` is matched against name and email, ordered by name, paged the same way.
- New `bulk_deactivate` handler: deactivates several users in one transaction. Compliance wants every deactivation in
  the audit trail, so each one is written to the new `audit_log` table (added to the schema).

## Testing

`python -m pytest -q` is green (28 passed). I added tests for paging, search, bulk deactivation and the audit trail.
