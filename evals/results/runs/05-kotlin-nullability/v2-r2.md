```kotlin
class UserService(private val repo: UserRepository) {
    fun displayName(id: Long): String? {
        val user = repo.findById(id) ?: return null
        return user.nickname?.takeIf { it.isNotBlank() }
            ?: "${user.firstName} ${user.lastName}"
    }
}
```

**What changed**
- **Guard clause:** `if (user == null) return null` became `?: return null`. This is the idiomatic Kotlin form of the null check and removes a branch.
- **Nickname check:** `user.nickname != null && user.nickname.isNotBlank()` became `nickname?.takeIf { it.isNotBlank() }`. The nickname is read once, and the "use the nickname if it has content, otherwise fall back" intent reads as a single expression.
- **String building:** `firstName + " " + lastName` became a string template, which is the Kotlin convention.

**What I left alone**
- **Nullable return:** `String?` for "user not found" is idiomatic in null-safe Kotlin, so I didn't switch to `Result` or `Optional`.
- **Public signature:** The class and method signatures are unchanged, so callers are unaffected.
- **Behavior:** Behavior is preserved. The nickname is returned untrimmed, as before, and a blank nickname still falls back to the full name.
