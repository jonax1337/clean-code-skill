Both symptoms come from `summarize` receiving an empty `orders` array:

- `average([])` computes `0 / 0`, which is `NaN`, so `avg` becomes the string `"NaN"`.
- `Math.max(...[])` returns `-Infinity`.

**Fix in `stats.js`:**

```js
function summarize(orders) {
  if (orders.length === 0) {
    return { count: 0, avg: '0.00', max: 0 };
  }

  const amounts = orders.map(o => o.amount);
  return {
    count: orders.length,
    avg: average(amounts).toFixed(2),
    max: Math.max(...amounts),
  };
}
```

**Notes:**

- **Empty-state values:** I chose `avg: '0.00'` and `max: 0` so the return shape and types stay the same and the dashboard needs no changes. If you'd rather show "–" or "n/a" for customers without orders, return `null` for those two fields and handle it in the UI. That's your product decision.
- **`average` unchanged:** I left `average([])` returning `NaN`. The mean of nothing is undefined, and the guard in `summarize` covers this bug. Other callers of `average` may need their own handling, so check them.
