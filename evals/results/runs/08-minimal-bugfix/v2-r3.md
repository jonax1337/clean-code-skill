Both symptoms come from `summarize` receiving an empty `orders` array:

- `average([])` computes `0 / 0`, which is `NaN`, so `toFixed(2)` gives `"NaN"`.
- `Math.max(...[])` returns `-Infinity`.

```js
// stats.js
function average(values) {
  if (values.length === 0) return 0;
  let sum = 0;
  for (const v of values) sum += v;
  return sum / values.length;
}

function summarize(orders) {
  const amounts = orders.map(o => o.amount);
  return {
    count: orders.length,
    avg: average(amounts).toFixed(2),
    max: amounts.length === 0 ? 0 : Math.max(...amounts),
  };
}

module.exports = { average, summarize };
```

**Decision for you:** I chose `0` / `"0.00"` for the empty case because it keeps the return types unchanged, so the dashboard code needs no changes. If you'd rather show "no data" (for example `—`), return `null` for `avg` and `max` instead and have the dashboard render that. That is a small change, but it alters the shape the UI receives.
