Here's the customer repository, mirroring the order one:

```csharp
using Microsoft.EntityFrameworkCore;

public interface ICustomerRepository
{
    Task<Customer?> GetByIdAsync(Guid id, CancellationToken ct);
    Task<Customer?> GetByEmailAsync(string email, CancellationToken ct);
    Task AddAsync(Customer customer, CancellationToken ct);
}

public sealed class SqlCustomerRepository : ICustomerRepository
{
    private readonly DbContext _db;

    public SqlCustomerRepository(DbContext db) => _db = db;

    public Task<Customer?> GetByIdAsync(Guid id, CancellationToken ct) =>
        _db.Set<Customer>().FindAsync(new object[] { id }, ct).AsTask();

    public Task<Customer?> GetByEmailAsync(string email, CancellationToken ct) =>
        _db.Set<Customer>().FirstOrDefaultAsync(c => c.Email == email, ct);

    public async Task AddAsync(Customer customer, CancellationToken ct)
    {
        _db.Add(customer);
        await _db.SaveChangesAsync(ct);
    }
}
```

Notes:

- **Assumption:** I can't see `Customer`, so I assumed it has a `string Email` property and a `Guid` key, as `Order` does. Adjust if the names differ.
- **Same style as `SqlOrderRepository`:** same constructor, same `FindAsync` lookup, and `AddAsync` saves immediately. `GetByEmailAsync` returns a tracked entity, like `GetByIdAsync`, so callers can modify and save it the same way.
- **Case sensitivity:** `c.Email == email` is translated to SQL, so whether `Jane@x.com` matches `jane@x.com` depends on the column collation. SQL Server's default is case-insensitive, while PostgreSQL's is case-sensitive. If you need guaranteed behavior, normalize emails on write and on lookup (e.g. `ToLowerInvariant()`), or use a case-insensitive collation on the column. I didn't add normalization since it changes how `Customer` is stored, which goes beyond this request.
- **Uniqueness:** `FirstOrDefaultAsync` assumes email is unique. A unique index on `Email` in your model configuration would enforce that. I haven't touched it since I haven't seen your mapping.
- **DI registration:** remember to register `ICustomerRepository` alongside `IOrderRepository`. I haven't seen your composition root, so I didn't add it.
