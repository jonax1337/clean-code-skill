I added `formatted_invoice_total` to `billing/invoice.py`. It reuses `invoice_total` and `format_currency`, so the rounding and German number format stay in one place.

```diff
 def invoice_total(items) -> Decimal:
     return calc_net(items) + calc_vat(items)
+
+
+def formatted_invoice_total(items) -> str:
+    return format_currency(invoice_total(items))
```

For example, a single item with price `1000` and qty `1` gives net 1000 + VAT 190, so `formatted_invoice_total(items)` returns `"1.190,00 EUR"`.
