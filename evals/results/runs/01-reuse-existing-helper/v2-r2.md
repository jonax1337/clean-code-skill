I added one function that reuses `invoice_total` and `format_currency`, so no formatting logic is duplicated:

```python
def invoice_total_display(items) -> str:
    return format_currency(invoice_total(items))
```

- **Output format:** `format_currency` already produces the German style (`1.234,50 EUR`), including `ROUND_HALF_UP` rounding to cents, so the footer string comes out in that format.
- **Rounding:** `invoice_total` stays unrounded, and rounding happens only when the string is built. The footer can therefore differ by a cent from a total that was rounded earlier, for example per line or per VAT amount. If your invoices must round the VAT separately, that would be a change to `calc_vat`, which I left alone.
- **Currency:** I didn't add a `currency` parameter, since nothing needs one yet. The default `"EUR"` applies.
- **Verification:** I couldn't run anything in this session, so this is untested. A quick test would be one item with price `1234.50` and qty `1` at 19% VAT. That gives a gross of `1469.055`, which should display as `1.469,06 EUR`. This also checks the half-up rounding.
