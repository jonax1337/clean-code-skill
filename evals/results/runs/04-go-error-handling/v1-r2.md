```go
func (s *Server) handleGetUser(w http.ResponseWriter, r *http.Request) {
	id, err := parseUserID(r)
	if err != nil {
		http.Error(w, err.Error(), http.StatusBadRequest)
		return
	}

	user, err := s.db.FindUser(r.Context(), id)
	if err != nil {
		respondToFindUserError(w, id, err)
		return
	}

	writeJSON(w, user)
}

func parseUserID(r *http.Request) (int, error) {
	raw := r.URL.Query().Get("id")
	id, err := strconv.Atoi(raw)
	if err != nil {
		return 0, fmt.Errorf("invalid user id %q: must be an integer", raw)
	}
	return id, nil
}

func respondToFindUserError(w http.ResponseWriter, id int, err error) {
	if errors.Is(err, store.ErrNotFound) {
		http.Error(w, "user not found", http.StatusNotFound)
		return
	}
	log.Printf("find user %d: %v", id, err)
	http.Error(w, "internal server error", http.StatusInternalServerError)
}

func writeJSON(w http.ResponseWriter, value any) {
	w.Header().Set("Content-Type", "application/json")
	if err := json.NewEncoder(w).Encode(value); err != nil {
		log.Printf("write json response: %v", err)
	}
}
```

**What changed**

- **Swallowed `Atoi` error (G4, G3):** A missing or malformed `id` silently became `0`. It now returns `400 Bad Request` with a message that names the bad input.
- **Log-only `catch`:** The old code logged the error and then went on to encode a nil user as a `200`. Now every error path responds and returns.
- **Not found vs. real failure:** `errors.Is(err, store.ErrNotFound)` maps to `404`. Anything else is logged with context (operation and id) and returns `500`. The client gets a generic message, so no internals leak.
- **Encode error:** It is no longer ignored. Once the body has started, the status can't change, so logging is the only sensible reaction there.
- **Structure (G30, G34):** The handler now reads as a short story at one abstraction level: parse, find, respond. The details sit in small helpers below it (stepdown rule).

**Assumptions:** `log` is your project's logger (swap in `slog` or whatever you use), and `FindUser` returns `store.ErrNotFound` directly or wrapped with `%w`, which `errors.Is` handles. If you use `any` in an older Go version (before 1.18), replace it with `interface{}`.
