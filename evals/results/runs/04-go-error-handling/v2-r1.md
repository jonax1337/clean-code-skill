```go
func (s *Server) handleGetUser(w http.ResponseWriter, r *http.Request) {
	id, err := strconv.Atoi(r.URL.Query().Get("id"))
	if err != nil {
		http.Error(w, "invalid user id", http.StatusBadRequest)
		return
	}

	user, err := s.db.FindUser(r.Context(), id)
	if errors.Is(err, store.ErrNotFound) {
		http.Error(w, "user not found", http.StatusNotFound)
		return
	}
	if err != nil {
		log.Printf("handleGetUser: find user %d: %v", id, err)
		http.Error(w, "internal server error", http.StatusInternalServerError)
		return
	}

	w.Header().Set("Content-Type", "application/json")
	if err := json.NewEncoder(w).Encode(user); err != nil {
		log.Printf("handleGetUser: encode user %d: %v", id, err)
	}
}
```

You'll need to add `"errors"` to the imports.

**What changed**

- **Swallowed `Atoi` error:** a missing or malformed `id` silently became `0` and queried the wrong user. It now returns 400.
- **Log-and-continue on `FindUser`:** the old code logged the error and then encoded a zero-value `user` as a 200 response. Each failure now returns immediately with the right status.
- **`ErrNotFound`:** checked with `errors.Is` (so wrapped errors still match) and mapped to 404, separate from real failures.
- **Unexpected errors:** logged with the operation and the input id, while the client gets a generic 500 so internals don't leak.
- **`Encode` error:** no longer ignored. By then the status line is already sent, so the only useful action is to log it.
- **Content-Type:** set to `application/json` before writing the body.
